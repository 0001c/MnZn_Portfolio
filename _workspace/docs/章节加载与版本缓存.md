# MP4章节加载、资源版本缓存与目录整理 · 2026-10-15

## 当前行为

恢复三段MP4，滚动视频仍使用原全关键帧版本，不改变编码、尺寸或画质。进入页面立即加载主视频；第三屏入场与循环元素只有data-src、preload=none，首次故事时间达到3.5秒（第二屏履历）才设置src并load；只触发一次。直接进入第三屏、恢复靠后位置也适用。错误时使用原MP4兜底，兜底只有出错才下载。

## 版本与缓存

构建递归分析index.html、脚本和内容JSON引用的站内文件，将转换后的内容SHA-256前12位插入文件名。依赖更新会向上更新JSON/脚本和HTML中的地址。源文件路径仍保持原名，避免本地编辑混入自动生成地址。npm run build生成dist，每次清空并重建该明确目录，不修改原始素材。

发布资产一年Cache-Control public/max-age=31536000/immutable；入口HTML为no-cache，意味着检查新版本后可复用，不是完全禁止存储。_headers复制到dist供Netlify应用；netlify.toml指定构建命令与publish=dist。其它托管服务需自行配置响应头。本地发布服务器支持相同缓存策略、ETag/304和Range/206。源文件预览使用npm run dev，各未版本化文件仍no-cache。

## 实测

本机Edge独立无缓存上下文，以首屏主视频就绪并等待1.5秒为观察点，进入第二屏、两片就绪再等待0.6秒为下一观察点。单位MB为1,000,000字节，CDP统计完成请求编码传输字节（含HTTP头），不含TLS链路开销。

| 视口 | 首屏MB | 履历屏累计MB |
| --- | ---: | ---: |
| 1440×900 | 18.551 | 28.619 |
| 390×844 | 18.551 | 28.619 |

恢复MP4使完整浏览流量高于此前WebM的13.75MB，但恢复快速随机寻帧；章节懒加载将MP4版首访约28.62MB降为18.55MB（减少约35.2%），完整浏览仍约28.62MB。两组首屏仅一条主视频MP4请求，第三屏两片仅在履历阶段出现。没有WebM请求或脚本/HTTP错误。第三屏坐下入场、工作循环和向上返回均通过。

直接第三屏与人为延迟第三屏媒体1秒加载在减少动态效果模式下通过。重复访问同一浏览器上下文观察期间仅226字节网络传输，图集从磁盘缓存读取，其余资源可由浏览器内存/媒体缓存复用；实际跨设备、缓存清除或长期未访问的结果不同，不承诺始终为此数值。长效缓存响应头、video/mp4、Range 206及1024字节片段、ETag 304、入口no-cache都验证通过。

## 目录与素材

- dist：22个版本化资产及入口/缓存规则，约36.40MB，包括正常不会下载的两段原始MP4兜底文件。仅发布此目录。
- 根index.html、assets和content是当前源文件。原始主视频.mp4及尾部视频.mp4因被错误兜底/无脚本观看引用继续保留；未使用原片、WebM、PNG/JPEG、旧图集和提示词归档到_workspace/original-assets/assets/。
- 旧app.js/style.css/HTML副本归档到_workspace/legacy-root；历史archive、参考、3d、文档、工具、测试、分析、截图和45份旧日志集中_workspace。素材没有删除。
- 编辑器迁移到_workspace/editor/content-editor.html，CSS/JS一起迁移；脚本和说明链接、内容JSON与封面预览路径已修复。npm run dev时可使用，发布包不含编辑器。编辑器加载个人资料和7件作品无HTTP/脚本错误。
- 此次及后续日志按既有约定位于根log，历史在_workspace/log；二者都不发布。

## 验证与复测

npm run check会先重建发布包并检查语法、资源、字段及内容哈希；npm test验证人物和视频全流程。浏览器专项脚本为_workspace/tools/verify-chapter-loading.cjs，默认http://127.0.0.1:4173，可用PREVIEW_URL覆盖；依赖Playwright/Edge，可用PLAYWRIGHT_MODULE指定模块。证据为_workspace/analysis/chapter-loading/qa.json、editor-qa.json。文件清单为_workspace/manifests/runtime-assets.json与non-runtime-files.json。

修改图片、视频或JSON后务必重新build及发布dist，勿手工修改dist或将整个项目目录拖到托管平台。
