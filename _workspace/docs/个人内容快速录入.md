# 个人内容快速录入

第二屏显示个人简介、能力标签和逐项履历：一次突出一段，滚动时大年份按方向翻动、标题滑入、进度刻度更新，向上可回看；窄屏履历面板采用更透明的iOS风格圆角毛玻璃。仅隐藏浏览器主滚动条，底部进度区保持显示，滚动与章节导航仍可使用。第三屏显示沿屏幕内立体圆环循环的作品卡牌，悬停时随鼠标倾斜：点击停驻并显示简介，再次点击展开圆角详情；关闭后收缩回卡牌、归位并继续流动，分类可停驻作品，左右按钮旋转整个圆环，详情内的上一件/下一件切换项目。停止滚动后人物会完成坐下并循环操作电脑；向上滚动直接回到第二屏第一段履历。作品详情弹窗保留自身滚动。所有资料读取 `content/portfolio.json`，作品图片放在 `assets/images/works/`，无需修改页面或视频代码。

## 用表单录入

1. 在项目目录执行 `npm start`，打开终端显示的本地网址，例如 `http://127.0.0.1:4173/`。本次预览是 `http://127.0.0.1:4180/`。
2. 在地址后加 `/content-editor.html`。点击“打开现有内容文件”，选择项目内的 `content/portfolio.json`。Chrome / Edge 支持直接保存回该文件；其他浏览器可导入 JSON 后下载替换。
3. 填写姓名、身份、简介、技能和邮箱。邮箱可留空，网站会隐藏联系入口。简介和经历都换成真实资料后，取消“个人资料和履历为演示内容”。
4. 点击履历或作品卡片标题展开 / 收起，支持键盘 Enter / 空格。新增和复制卡片会自动展开，折叠不会丢失填写内容。添加经历，填写年份、学校/公司、职位与描述；用上移/下移调整顺序。选为草稿的内容不会在前台显示。
5. 将图片复制到项目里，例如 `assets/images/works/coffee-brand/cover.jpg` 和 `assets/images/works/coffee-brand/detail-01.jpg`。表单不会自动上传或复制图片。
6. 添加作品或复制现有作品，填写标题、唯一标识、年份、分类、简介、详情、封面路径、图片说明、职责、工具和排序。唯一标识如 `coffee-brand`，只能包含英文小写字母、数字和连字符。详情图片路径每行一张。作品链接可留空，每行填写一个完整的 `https://` 或 `http://` 网址；空行会忽略，保存后在作品详情中逐行显示，点击在新标签页打开。
7. 取消真实作品的演示标记，将状态设为“已发布”。路径格式正确不代表图片存在，请通过封面预览确认文件。
8. 点击“保存到内容文件”。第一次保存务必选择当前项目的 `content/portfolio.json`。不支持直接保存时，点击“下载 JSON”，用下载结果替换该文件。仅下载到其他目录不会更新网站。
9. 刷新网站检查第二、第三屏与案例详情。演示项目可设为草稿或删除后保存。

直接打开 `index.html` 的 `file://` 地址可能无法读取 JSON，请通过本地 HTTP 服务预览。编辑页只保存本机文件，没有联网后台；已经上线的网站需要同步修改后的 JSON 和新增图片才会更新。

## 交给当前聊天批量录入

把作品图片按项目分文件夹放在 `assets/images/works/`，填写 `docs/个人资料与作品录入模板.md`，再告诉当前聊天：

> 请读取个人资料与作品录入模板，把真实内容写入 content/portfolio.json。图片在 assets/images/works/，替换演示履历和演示作品；缺失信息请保留为空或草稿，不要虚构成果。

一次提供多个项目即可批量整理。每个项目至少提供项目名、年份、分类、你的职责、简短背景和封面路径。详情最好补充“问题 → 做法 → 结果”；没有可验证数据时描述实际交付物。

## 内容规则

| 内容 | 位置 | 显示规则 |
| --- | --- | --- |
| 姓名、身份、标语、简介、技能、邮箱 | `profile` | Logo/首页身份、第二屏简介、第三屏联系入口 |
| 年份、学校/公司、职位、描述 | `experience` | 按数组顺序显示，仅 `status: published` 可见 |
| 分类名称和顺序 | `categories` | 沿用作者七类；可直接编辑 JSON 修改中英文名称与顺序 |
| 作品 | `projects` | 按分类顺序集中排列，同类按 `sortOrder` 升序；仅已发布可见 |
| 封面 | `cover`、`alt` | 建议 1600×900 JPG/WebP，重要内容留在中央；流动卡牌裁成约 1.45:1，详情保留原比例 |
| 详情图片 | `images` | 在封面后依次展示；点击打开原尺寸图 |
| 作品链接 | `links` | 可选的网址数组，按录入顺序每行一个；没有链接时隐藏，兼容旧文件未包含此字段 |
| 真实/演示 | `demo` | 真实内容设置 `false`；个人资料和作品分别控制标记 |

目前支持图片封面和多张详情图，未接作品视频上传、云端媒体库或 Sanity CMS。主视频和第三屏过渡由滚动控制；第三屏停止后自动补完，再播放操作电脑片段。草稿只是不在前台展示，JSON 本身可被网站访客读取，不要存放保密内容。

新增资源 `content/portfolio.json`、`assets/portfolio-model.js`、`assets/portfolio-content.js`、`assets/portfolio-content.css` 和所引用图片需要随页面交付。`content-editor.html` 与两份 `content-editor` 资源是本机编辑工具，可不部署；它们没有服务器写入接口，不是有鉴权的线上后台。
