- npm run test:legacy 引用历史测试，部分测试仍依赖已经归档的源文件；本次保留其脚本但未执行，不代表旧测试可用。
- 仅创建本地仓库并提交，没有配置远程或推送。
- 新增被忽略目录中的文件时须确认是否需要调整 .gitignore；后续新增主页资源可直接放 assets。
